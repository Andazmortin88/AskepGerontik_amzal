# Checkpoint animasi landing Askep Gerontik

Status: belum dirender, jangan publikasikan sebagai animasi final.

Sumber yang dipilih pengguna: Andaz Health Presenter Explains Geriatric Care(1).gif, 772473 byte. Pengambilan berkas gagal dan piksel belum dapat diperiksa. Permintaan edit terbatas pada tulisan background menjadi **Askep Gerontik**, mempertahankan karakter dan gerak.

Remotion dipin pada package.json. Instalasi lokal belum berhasil karena symlink ditolak perangkat. Belum ada dependency lockfile atau hasil render yang dapat diverifikasi.

Setelah sumber dan renderer tersedia:
1. Baca metadata dan periksa frame awal, tengah, akhir. Jangan menebak area masker latar sebelum sumber dilihat.
2. Simpan source terpisah dari output. Ganti hanya tulisan di area latar; jangan menutupi wajah, tangan atau busana karakter.
3. Susun komposisi Remotion dengan gerak asli dan judul Askep Gerontik. Tidak menambah suara atau lip-sync baru.
4. Render H.264 untuk landing, poster statis dan versi ponsel bila diperlukan. Durasi mengikuti sumber dan brief loop pendek; tidak crop berulang.
5. Periksa frame, teks, kompresi, pause/replay dan reduced motion. Integrasikan ke landing premium setelah lolos pemeriksaan.
