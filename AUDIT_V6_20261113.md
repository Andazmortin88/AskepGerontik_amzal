## Pengujian otomatis
Perintah terakhir: node --test tests/*.test.cjs. **64 lulus, 0 gagal**. Mencakup:
- 17 instrumen dan semua ID/rentang/opsi asli tetap konsisten.
- Setiap jawaban wajib kedua minggu; skor nol sah; nilai di luar rentang ditolak.
- Pemisahan cache per akun, pergantian akun saat respons tertunda, konflik dua perangkat, antrean perubahan dan pengiriman ulang aman.
- Pembatasan handler: tanpa token, origin asing, mahasiswa mengimpor roster, dosen menyimpan sebagai mahasiswa, mahasiswa membuka FINAL, revisi review usang.
- Model migrasi mempertahankan field, ID aktivitas, narasi lama, rencana SLKI/SIKI lama dan review dari server.
- Semua 18 view sumber terdefinisi; 17 view non-PDF dirender pada kedua peran dalam VM.
- Simulasi 100 pengguna: puncak 100 panggilan transport, 100 dokumen disimpan dan dibaca kembali secara terpisah. **Transport dan autentikasi tiruan, 0 permintaan produksi, 0 login Google.**

## Perbaikan keamanan dan sinkronisasi
- Pemilih peran demo disembunyikan dan tidak menentukan hak server; cache demo tidak dibaca sebelum autentikasi.
- Nama/NIM/program/kelompok berasal dari roster dan dikunci pada mahasiswa.
- Status review, rubrik, penilai dan operasi review diproses server; mahasiswa tidak dapat menetapkan otoritas penilaian melalui state lokal.
- Penulisan memakai revisi dan operationId; konflik tidak diam-diam menimpa dokumen.
- FINAL menonaktifkan field setelah render ulang; pembukaan koreksi membutuhkan dosen dan alasan tercatat.
- Arsip PDF menggunakan penyimpanan privat dan tautan bertenggat, diperiksa terhadap lingkup akun.
- PDF yang dibuat sebelum perubahan portofolio harus dibuat ulang sebelum diarsipkan.
- Batal pada dialog keputusan PDF membatalkan tindakan; permintaan revisi memiliki tombol sendiri.
- Panggilan API dibatasi waktu; unggahan PDF memiliki batas waktu 60 detik. Jalur browser pemilihan berkas belum lulus: otomasi tersendat dan tab uji sempat gagal. Jalur arsip langsung dari PDF yang dihasilkan telah berhasil.

Supabase health terakhir tidak melaporkan temuan. Security advisor melaporkan INFO RLS tanpa policy pada 48 tabel; akses aplikasi ini memakai backend service yang mengotorisasi sendiri, bukan membuka tabel langsung. Jangan menambah policy permisif untuk menghilangkan informasi tersebut. Ada WARN perlindungan password bocor belum aktif; aplikasi yang diuji memakai Google OAuth. Rujukan: https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection dan https://supabase.com/docs/guides/database/database-linter?lint=0008_rls_enabled_no_policy.

Audit keamanan repository terkelola belum dapat dijalankan karena alat scan yang dibutuhkan tidak tersedia. Pemeriksaan handler dan konfigurasi di atas bukan pengganti pentest menyeluruh.

- Bobot, rubrik formatif dan target berasal dari draf RPS; tidak dijadikan nilai akhir/keputusan kelulusan otomatis.
